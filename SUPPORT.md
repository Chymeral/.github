# Support

## Documentation first

- For terminal installation, configuration, CLP concepts, and runtime behavior,
  start with the [Chymeral Main Manual](https://github.com/Chymeral/chymeral/blob/main/Main_Manual.md).
- For Rust client development, start with the
  [Chymeral Rust SDK README](https://github.com/Chymeral/chymeral-rust-sdk#readme)
  and its [API documentation](https://docs.rs/chymeral-rust-sdk/1.0.0/chymeral_rust_sdk/).
- For Node.js or TypeScript client development, start with the
  [Chymeral Node SDK README](https://github.com/Chymeral/chymeral-node-sdk#readme)
  and its [npm package](https://www.npmjs.com/package/@chymeral/node-sdk).

## Report the right thing in the right place

- **Bug:** Open a reproducible issue in the repository that owns the behavior.
- **Feature proposal:** Open an issue in the relevant repository and explain the
  use case, alternatives, and effect on the language-neutral CLP contract.
- **Documentation correction:** Open an issue or pull request in the repository
  containing the document.
- **Security issue:** Follow the applicable [security policy](SECURITY.md); do
  not use public issues.

The organization does not provide a separate hosted support channel. Keep issue
trackers focused on actionable, reproducible work so maintainers and contributors
can respond effectively.
