# Security Policy

## Scope

This is the default security policy for Chymeral repositories that do not
provide a more specific one. A repository-specific policy takes precedence.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities through a public issue, discussion,
or pull request. Use the affected repository's GitHub private
vulnerability-reporting channel when it is available.

If private reporting is temporarily unavailable, contact a Chymeral organization
owner privately through GitHub. Include the affected repository and version,
platform, impact, reproduction steps, and any proposed mitigation. Please allow
maintainers reasonable time to investigate and coordinate a fix before public
disclosure.

For the currently published projects, use their repository-specific policies:

- [Chymeral security policy](https://github.com/Chymeral/chymeral/blob/main/SECURITY.md)
- [Chymeral Rust SDK security policy](https://github.com/Chymeral/chymeral-rust-sdk/blob/main/SECURITY.md)
